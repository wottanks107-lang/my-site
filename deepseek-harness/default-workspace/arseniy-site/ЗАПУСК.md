# Как запустить сайт

## Что нужно один раз

1. **Node.js 20 или новее** — скачать с https://nodejs.org (кнопка LTS).
   Проверить, что установился: открой терминал и напиши `node -v` — должно показать `v20…` или выше.
2. **Файл `.env.local`** в папке проекта — в нём пароль от админки и ключи Supabase.
   В архивах его нет (там секреты), поэтому возьми его из рабочей копии проекта
   или создай сам по образцу `.env.example`.

## Запуск — 4 шага

**Шаг 1.** Открой папку проекта в проводнике.

**Шаг 2.** Открой в ней терминал: щёлкни по адресной строке проводника, напиши `cmd` и нажми Enter.
(Или правый клик по папке → «Открыть в терминале».)

**Шаг 3.** Первый раз установи зависимости — введи и подожди:

```
npm install
```

**Шаг 4.** Запусти сайт:

```
npm run dev
```

В терминале появится строка вида `Local: http://localhost:3000`.
Открой этот адрес в браузере — сайт работает.

**Остановить сайт:** нажми `Ctrl + C` в терминале.

## Вход в личный кабинет

1. Открой http://localhost:3000
2. В шапке справа нажми **«Войти»** (или сразу http://localhost:3000/dashboard)
3. Пароль: `arseniy2026` — поменяй его в `.env.local` в строке `ADMIN_PASSWORD`

Разделы: Обзор, Расписание, ДЗ, Заметки, Проекты, Цели, Тренировки, Книги, Профиль, Настройки.

## Как обычный (не dev) запуск

`npm run dev` — режим разработки: сайт сам перезагружается при правках, но он медленнее.
Чтобы запустить «по-настоящему»:

```
npm run build
npm start
```

## Если что-то не работает

| Что видишь | Что делать |
|---|---|
| `npm: команда не найдена` | Не установлен Node.js — шаг 1 |
| `EADDRINUSE: address already in use :3000` | Порт занят: закрой другой терминал с сайтом или перезапусти компьютер |
| Открывается, но данных нет | Нет файла `.env.local` или в нём неверные ключи Supabase |
| `Не удалось загрузить…` в dashboard | Проверь связь с базой: `npm run check:db` |
| Всё сломалось, хочу проверить | `npm run lint` — покажет ошибки в коде |

## Полезные команды

| Команда | Что делает |
|---|---|
| `npm run dev` | запустить сайт для работы |
| `npm run lint` | проверить код на ошибки |
| `npm run build` | собрать версию для публикации |
| `npm start` | запустить собранную версию |
| `npm run check:db` | проверить базу: таблицы, доступы, Storage |
| `npm run migrate` | перенести старые данные из `data/content.json` в базу |
| `npm run db:migrate` | создать таблицы в базе (нужен раз) |

## Как выложить сайт в интернет

Сейчас сайт виден только на твоём компьютере. Чтобы он открывался у всех,
нужен хостинг. База уже в облаке (Supabase), поэтому подойдёт бесплатный Vercel:

1. Залей проект на GitHub.
2. На https://vercel.com создай проект из этого репозитория.
3. В настройках Vercel добавь те же переменные, что в `.env.local`
   (`ADMIN_PASSWORD`, `AUTH_SECRET`, `NEXT_PUBLIC_SUPABASE_URL`,
   `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SERVICE_ROLE_KEY`).
4. Нажми Deploy.

Подробности — в `README.md`.
